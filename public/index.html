og/image

Docs

A social card is one URL.

Put the title in the query string, get a 1200×630 PNG back. Paste it in your og:image tag and stop screenshotting.

Try it

Enter a key to render. Keys are issued by the operator.

Reference

GET /v1/og?title=Hello&subtitle=World&theme=dark&template=split&accent=ff5500
X-API-Key: og_...      (or ?key=og_... so it works inside a meta tag)
  • title required, max 140 chars
  • subtitle optional, max 200
  • site optional label, max 60
  • template default | split | minimal
  • theme dark | light
  • accent 6-digit hex, no #

Usage: GET /v1/usage with your key. Plans: Free 100 cards/month, Pro 10,000, Business 100,000. Over quota returns 429 QUOTA_EXCEEDED.

Latin text only for now (Inter). Arabic and CJK are not supported yet.
